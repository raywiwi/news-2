# Página de Noticias

Proyecto frontend desarrollado con HTML, CSS y JavaScript puro.

## Funcionalidades
- Slider de noticias en tiempo real (API The Guardian)
- Sección de deportes actualizada automáticamente
- Formulario de contacto con validaciones en JavaScript
- Diseño responsive móvil y desktop

## Tecnologías
- HTML5 / CSS3
- JavaScript ES6+
- API REST (The Guardian)
- Git / GitHub
